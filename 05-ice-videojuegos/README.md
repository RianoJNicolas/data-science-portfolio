# Tienda de videojuegos Ice

> **Estado: en progreso.** Hasta ahora están hechas la carga de datos y la exploración inicial.

## Contexto

La tienda en línea Ice vende videojuegos en todo el mundo. A partir de datos históricos de ventas, reseñas de usuarios y expertos, géneros y plataformas, el objetivo es identificar qué patrones determinan si un juego tiene éxito y usar esos hallazgos para planificar campañas publicitarias.
